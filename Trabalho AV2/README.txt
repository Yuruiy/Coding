Nome do Arquivo: Quiz.py
Titulo: QUIZ DE PROGRAMAÇÃO

O sistema é um quiz com base no que vimos na aula passada, dessa vez eu botei 10 questões sobre programação e usei como base o modelo que já havia sido ensinado na aula aprofundando com o uso de funções

*Parte do sistema foi revisado em casos de erros com o Chat GPT, mas o sistema inteiro teve minha autoria e mesmo quando uma alternativa era sugerida eu verificava previamente como afetaria.

(Infelizmente não pude ir pra aula devido a problemas de saúde, mas como vi a atividade quis fazer, foi uma experiência interssante fazer o sistema sem nenhuma assitência humana)
